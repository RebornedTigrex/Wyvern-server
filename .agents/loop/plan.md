# План задач (plan.md)
Источник задач - канбан-доска `Source/Канбан проекта.md`. Этот файл её не дублирует, а объясняет, как с ней работать. Общий контекст проекта - в `AGENTS.md` (корень репозитория).
## Где лежат задачи
- Доска: `Source/Канбан проекта.md`, формат плагина Obsidian Kanban.
- Колонки: `Нужно` -> `В работе` -> `Завершено`. Отдельно `Техдолг` - оттуда ничего не берём, пока не закрыт MVP.
- Внутри `Нужно` карточки упорядочены по зависимостям: берём верхнюю, а не понравившуюся. Порядок подобран так, чтобы сборка оставалась зелёной после каждой задачи.
## Цикл работы
1. Прочитай `AGENTS.md` для контекста.
2. Возьми верхнюю карточку из `Нужно` и перенеси её в `В работе`.
3. Выполни по протоколу из `AGENTS.md`: уточнение контракта -> подтверждение -> чекпоинты C1-C4.
4. Сверься со строкой `Готово:` в карточке - это Definition of Done, других критериев не выдумываем.
5. Перенеси карточку в `Завершено` и поставь `[x]`.
6. Обнови `.agents/loop/status.md`: что сделано, где сломалось, что проверить дальше.
7. После изменений в коде прогони `graphify update .` из каталога `Source`.
## Формат новой карточки
Если задача появляется по ходу дела - добавляй её на доску в том же виде:
- заголовок `- [ ] ### T-NNN - краткое название`;
- тело с отступом табом: 1-2 строки цели, затем список конкретных шагов;
- последняя строка тела - `Готово: <проверяемый критерий>`.
Не ломай служебный блок `%% kanban:settings %%` в конце файла и не заменяй табы пробелами - иначе плагин перестанет видеть карточки.
