# План задач (plan.md)
Источник задач для агентов: агент берёт отсюда следующую задачу. Общий контекст проекта - в `AGENTS.md` (корень репозитория).
## Как пользоваться
- Задачи упорядочены по приоритету (P0 - выше всего).
- Агент берёт первую незавершённую задачу, выполняет её по протоколу из `AGENTS.md`, затем фиксирует результат в `.agents/loop/status.md`.
- Формулируй задачу узко и проверяемо: у каждой задачи явный Definition of Done.
## Формат задачи
- ID: короткий идентификатор (напр. T-001).
- Приоритет: P0 | P1 | P2.
- Тип: feature | bugfix | refactor | test.
- Цель: 1-2 предложения.
- Границы: что можно менять, что нельзя (помни: `Source/Core/` пока не трогать).
- Definition of Done: список проверяемых критериев.
